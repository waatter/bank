# TROPOS 3.0.0 发布说明

发布日期：2026-10-27

## 本次版本定位

3.0 将 TROPOS 从本机银行沙箱扩展为“可部署的生活消费智能体演示版”。核心银行账本、画像、现金规划与安全确认边界继续保留，同时加入购物 Mock 全流程、美团官方跑腿连接器适配层、局域网演示和公共服务器部署能力。

## 主要新增

### 1. “帮我买”Mock 全流程

- 根据自然语言需求搜索合成商品，并按预算、类别与配送时效返回候选方案。
- 生成结算预览，服务端校验商品、地址、预算和账户版本。
- 每笔订单必须再次明确确认，并使用确认令牌与请求键防止重复提交。
- 确认后仅修改模拟银行账本，生成可追溯交易回执。
- 支持模拟订单状态推进和历史订单查询。

### 2. 美团官方跑腿 Skill 接口预留

- 增加授权状态、授权发起/完成、退出授权、地址簿、帮买报价、订单提交、收银台跳转和状态查询接口。
- 兼容官方连接器返回新授权链接或复用缓存登录态两种情况。
- 高额配送费需要额外确认；真实订单不会修改模拟银行账本，支付仍在美团官方页面完成。
- 云端发布包不包含个人美团令牌、真实地址、手机号或任何本机 Skill 私有数据。

### 3. 局域网与 Windows 启动支持

- Windows 提供一键启动脚本，可启动服务并打开演示页面。
- 局域网模式支持显式访问口令或免口令演示模式，并限制允许的私有地址 Host。
- 前端支持一次性接收局域网访问参数，随后从地址栏移除并保存在当前会话。

### 4. 公共服务器部署

- 新增 Docker 镜像和 Docker Compose 编排。
- Caddy 负责公网入口、自动 HTTPS、压缩和安全响应头。
- Python 应用仅监听服务器 `127.0.0.1:8765`，不直接暴露后端端口。
- SQLite 数据使用独立持久化目录；容器启用只读根文件系统和 `no-new-privileges`。
- 提供域名或临时公网 IPv4 两种初始化方式。

### 5. 测试与跨平台兼容

- 新增购物流程、美团跑腿适配和局域网访问测试。
- 修复 Windows/Python 3.13 下测试 SQLite 连接未显式关闭导致的文件占用问题。
- 评测源码哈希统一使用 POSIX 相对路径，保证 Windows 与 Linux 报告字段一致。
- 发布前完整测试：172 项全部通过。

## 与 2.0 的主要差异

| 方面 | 2.0 | 3.0 |
|---|---|---|
| 核心场景 | 生活规划、现金路径和行动建议 | 保留 2.0，并新增消费代理与跑腿帮买 |
| 购物能力 | 无完整购物闭环 | Mock 搜索、预算、确认、扣款、履约全流程 |
| 官方平台 | 未预留可运行连接器 | 美团跑腿 Skill 适配层与安全确认边界 |
| 运行范围 | 以本机演示为主 | 本机、局域网、Docker 公共服务器 |
| 公网入口 | 无标准部署方案 | Caddy 自动 HTTPS，后端保持回环监听 |
| 测试 | 原银行与生活规划测试 | 增加购物、连接器、局域网与跨平台测试 |

## 安全与产品边界

- 所有银行账户、交易、商品和 Mock 订单均为合成数据，不连接真实银行或支付系统。
- 公共服务器默认免登录时，所有访问者共享同一批模拟画像与账本；请勿录入真实姓名、账户、手机号、地址或资金信息。
- 当前版本不具备生产级用户注册、身份认证、角色权限、租户级数据隔离、审计运营后台或合规认证。
- 美团官方跑腿能力只有在用户本人完成官方授权、连接器可用且逐笔确认后才能提交；餐厅菜单外卖不属于本接口范围。

- `tropos-bank-v3.0.0-source.zip`：完整源码、文档和测试。
- `tropos-bank-v3.0.0-server.tar.gz`：面向 Linux Docker 服务器的部署包。

压缩包不包含 `.git`、`.local`、`.tmp`、生产环境变量、SQLite 数据库、缓存文件、个人令牌或本机密钥。
