# TROPOS 3.2.5 移动端美团授权体验更新

3.2.5 补齐手机端打开美团官方授权、手动刷新授权状态以及失败后重新授权的完整闭环。

## 主要变化

- 待授权期间展示“打开美团官方授权”，手机浏览器可以直接进入美团官方授权页面。
- 授权入口在有效期内保存在当前 TROPOS 服务进程的用户隔离内存中。刷新页面或重新进入“帮我买”后仍可重新打开；入口不会写入数据库，过期或授权结束后立即清除。
- 等待授权时提供“刷新授权状态”，并继续保留约 3 秒一次的自动检查以及页面重新获得焦点时的即时检查。
- 授权失败或过期后明确显示“重新授权”和“刷新状态”，不再让页面长期停留在不可操作的“正在同步”。
- 移动端授权按钮采用整行大按钮，方便在手机内置浏览器中点击，也不会与底部导航重叠。

## 安全边界

授权链接只返回给当前已登录用户，令牌仍由美团官方授权工具保存在每用户私有目录，不写入 TROPOS 数据库、网页、日志或模型上下文。此次更新不改变逐笔确认、支付跳转和用户数据隔离机制。

## 部署

使用 `deploy/docker-compose.update-3.2.5.yml` 更新 TROPOS 应用镜像即可。现有数据库、SMTP、模型配置、美团官方程序和每用户授权目录全部继续复用。
