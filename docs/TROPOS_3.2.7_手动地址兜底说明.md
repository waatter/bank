# TROPOS 3.2.7 手动地址兜底说明

## 本次改动

- 美团官方地址簿正常返回时，仍优先选择官方地址。
- 地址簿为空或地址接口暂时不可用时，页面提供“手动添加临时地址”。
- 临时地址包括城市、详细地址、门牌号、联系人和手机号；美团官方 `search_poi` 会把文字地址定位成经纬度，再进入官方询价与下单流程。
- 临时地址只用于本次询价和确认，不写入 TROPOS 地址簿或订单数据库；服务端订单只保存脱敏标签和不可逆指纹。
- 每笔真实跑腿仍需用户逐笔确认，并由用户在美团收银台完成支付。

## 限制

- 用户仍需完成本人美团账号授权。
- 如果美团 `search_poi`、询价或下单接口不可用，系统不会绕过官方接口创建订单。
- 手动填写地址不会同步到美团 App；如需长期使用，仍建议在美团 App 中维护地址簿。
