# TROPOS 3.2.4 美团授权同步热修复

3.2.4 修复用户已经在美团完成授权、TROPOS 页面却仍短暂显示“未授权”，需要反复点击检查的问题。

## 主要变化

- 美团授权改为按 TROPOS 用户隔离的后台轮询，同一用户同一时间只运行一个授权同步任务。
- 轮询窗口与官方授权入口一致，最长 10 分钟、每 3 秒检查一次，不再受原 60 秒 HTTP 请求限制。
- 网页在等待令牌期间每约 3 秒自动刷新，并在用户从美团页面返回、网页重新获得焦点时立即检查。
- “授权已确认、令牌尚在同步”显示为等待状态，不再误报为未授权；过期、取消及风控失败提供经过脱敏的明确提示。
- 授权任务使用随机尝试标识，旧任务不能覆盖新授权或断开后的状态。
- 地址簿与订单分别读取：其中一个接口失败不会把整个已连接状态清空。
- 已连接但地址簿为空时，页面提示先在美团 App 添加/完善地址，并提供“重新读取地址”按钮。

## 安全边界

授权令牌仍只保存在官方工具的每用户私有目录，不写入 TROPOS 数据库、网页、日志或模型上下文。后台轮询不会下单、付款或发起转账；所有真实跑腿订单仍需逐笔确认并在美团收银台完成支付。

## 部署

本次只需更新 TROPOS 服务包并使用 `deploy/docker-compose.update-3.2.4.yml`。已部署的私有美团连接器、授权状态目录和数据库继续复用，无需重新上传官方组件。
