# TROPOS 评委快速体验

咪咪大王队：刘水、余冠辰，复旦大学经济学院。

## 体验准备

按[部署指南](部署指南.md)启动，在浏览器打开 `/index.html` 后进入工作台。首次建档确认目标和读取同意。演示数据可能被先前操作改变，以下以界面当时状态为准。

## 三分钟主线

| 阶段 | 操作 | 观察重点 |
| --- | --- | --- |
| 理解处境 | 选择晓舟并完成画像，提出“帮我打理这两万元” | 目标、现金底线、未来最低余额与方案依据 |
| 千人千策 | 切换知远，完成画像后提出相同需求 | 不同现金条件如何影响可安排空间 |
| 随境而变 | 回到晓舟，使用演示事件模拟工资延期 | 已到账与预计收入分开，未来缺口与旧方案重新核验 |
| 办理一笔业务 | 选择现金条件允许的账户，提出小额转账，核对收款人、金额并确认 | 草案、明确确认、服务端记账、沙箱回执 |
| 看见后续 | 查看账单和订阅，比较某项取消的影响，再决定是否确认 | 操作如何改变未来安排，当前余额与未来节省分别呈现 |

## 可加演的细节

- 同名收款人先澄清，修改金额后重新形成待确认事项。
- 结果未知时按原事项查询回执，而不是另发一笔付款。
- 财务体检同时展示数据、规则、未知项与决定权。
- 长辈友好模式放大显示，确认要求保持一致。

银行数据及回执为合成。模型和美团为可选外部能力，基础体验无需密钥或真实订单。
