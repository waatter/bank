## 可核对的结果

- [首轮合成留出](../reports/v3-holdout-first.md)：**17/40 任务、28/79 步骤**通过，未授权变更0，错误草案12。失败与异常没有删除。
- [修复后回归](../reports/v3-holdout-regression-01.md)：**38/40 任务、74/79 步骤**通过；未授权变更0、错误草案0，恢复/重放10/10。它使用已公开的同一套题，**不是新的盲测成绩**。
- [首轮真实模型对照](../reports/v3-profile-comparison-first.md)：ordinary 8/12、static_profile 8/12、dynamic_profile 9/12。
- [修复后真实模型回归对照](../reports/v3-profile-comparison-regression-01.md)：ordinary 9/12、static_profile 10/12、dynamic_profile 10/12；选题和条件顺序与首轮完全相同。两轮共96次真实 `deepseek-flash` 调用，上游异常0、无输出修复或静默降级。
- 这些小样本不能确立动态画像优于静态画像或普通模型；三组共享网关，零未授权变更不能归为动态画像独有贡献。当前试验只比较工具选择与呈现条件，不验证风险量表或收益效果。工作台仍是规则模式；对照通道可用不表示线上模型已配置。
- 工程检查：**379项 Python、100项 Node 通过**；另包含脚本内部的31项HTTP工作台检查、16项画像不变量、9组风险规则和11项生活规划检查。不能把不同口径相加为真人样本。
- [最终本地只读检查](../reports/v3-local-final-readiness/readiness.md)：131项通过、0项失败、6项未测。属于单次本地GET与模板核对，不是长期稳定性。
- [公网只读检查](../reports/v3-public-readiness/readiness.md)：TLS失败，4个入口没有取得HTTP响应；现有证据不足以区分服务器证书/代理问题与网络路径问题。
- [手机模拟记录](../reports/v3-mobile-emulation.json)与[真人试用状态](../reports/v3-user-trial-status.md)分开保存；模拟不计入真人结果。

## 保留的两个口语限制

1. 完整新转账后附带“上次少给”的历史说明，仍触发历史指代澄清；可改为只说当前收款人、金额与时间。
2. “给我同事王磊…写报销”再夹带报销解释的连续更正尚不支持；可使用“给王磊（同事）转120元，备注报销”，再明确“改成108.01元”。

这两题没有生成错误可执行草案。对话原文、预期与失败点保留在回归JSON中，未来扩展语法后应重新做回归，并另取新的独立留出题，不能继续把旧题称作陌生任务。
