# TROPOS 3.2.8 模型自由对话与诊断说明

## 本版变化

- 普通知识问答、多轮讨论、比较、规划和写作改走模型原生文本输出，不再要求模型把自然语言强行包装成金融 JSON。
- 生日安排、购物方案和支出建议仍使用服务端脱敏财务摘要与预算上限，但允许模型用自然语言补充更完整的建议。
- 千问开启思考后若因共享输出额度导致正文被截断，会自动关闭思考重试一次，避免偶发显示“本次未调用”。
- DeepSeek、Kimi 和兼容接口的文本达到长度上限时，保留已经生成的安全正文，并提示用户继续追问。
- 页面展示经过脱敏的准确失败原因，例如密钥无效、余额不足、无模型权限、限流、网络不可达或输出被截断。

## 不会放开的能力

模型只能进行只读理解、解释与方案生成。转账、支付、下单、取消和账户修改仍由 TROPOS 服务端白名单、参数校验与逐步确认控制；模型不能绕过这些机制直接执行。
