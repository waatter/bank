## 下载与启动

解压 `TROPOS-2.0.zip` 后，进入项目目录运行 `./scripts/run.sh`，再打开 <http://127.0.0.1:8765/demo.html> 的“生活规划”。需要 Python 3.10 或更新版本，无需第三方 Python 包。未配置模型密钥时明确使用规则模式。

ZIP 包含源码、操作说明、检查用例和合成对照报告，不含个人账本、环境密钥、虚拟环境或 Git 历史。合作者运行后使用自己的合成数据。GitHub 共享源码，当前没有供多人远程使用的云端业务服务，也没有真实银行接入。
