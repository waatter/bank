# TROPOS 部署指南

## 本机快速运行（推荐评委体验）

Python 3.10+，运行后端无需第三方 Python 包。在仓库根目录执行：

```bash
python3 -m backend.server --host 127.0.0.1 --port 8765 --db .local/tropos.sqlite3
```

Windows 可改用 `python`，也可双击 `一键启动-TROPOS.cmd`。macOS/Linux 可运行 `sh scripts/run.sh`；该脚本可读取本机 `.env` 中允许的模型配置项。直接使用上面的 Python 命令时，配置应通过进程环境提供。

访问 `http://127.0.0.1:8765/index.html` 和 `/demo.html`。`/api/health` 返回版本及运行模式。SQLite 状态保存在 `.local/`，重启后保留；请保护该目录，勿上传个人凭证与本地数据库。

## 可选模型配置

无密钥时使用本地规则。需要外部模型时参考根目录 `.env.example` 和工作台模型中心。个人密钥按用户保存在服务进程内存，重启后需重新接入。外部请求可能发送用户消息、有限历史和相关汇总，调用费用由对应模型账户承担。

平台模型的运行时管理开关仅适合完全可信环境；它不是独立的管理员身份认证。

## Linux、Docker 与 HTTPS

仓库提供 `Dockerfile` 和 `deploy/` 配置。当前 Compose 为现有实例更新设计，构建上下文为 `deploy/build-context`，不能直接假设在根目录运行 Compose 即可部署。

请遵循[现有实例部署说明](../deploy/README.md)及其链接的构建上下文准备流程；新实例需自行配置域名、HTTPS、数据目录和必要的邮件与密钥环境。配置文件存在不代表已完成目标服务器验收。

## 网络访问

默认回环地址适合本机演示。安全复核发现局域网口令检查依赖请求自报 Host 的潜在绕过路径，尚需修复和动态验证；完成前应限制在可信本机访问，不把该口令作为对外访问保护。公网部署需重新核验代理、身份、权限、密钥和数据保留设置。

## 美团可选组件

Mock 与真实连接器分别运行。真实询价和订单依赖官方跑腿组件、Node 运行环境及用户本人授权。组件单独部署，相关姓名、电话、地址等会传给供应商，支付在美团完成。步骤见[组件部署说明](TROPOS_3.2.3_美团连接器部署说明.md)。

## 常见问题

- 端口占用：换用 `--port 8766`，并访问对应端口。
- 服务不可用：先查 `/api/health` 和启动终端信息。
- 模型未配置：基础规则模式仍可体验，模型中心显示缺少的配置。
- 账户状态与示例不同：前次操作会保留，金额以当前界面为准。
