# TROPOS 3.2.6 美团地址异常识别热修复

## 修复内容

- 正确识别美团官方组件“退出码为 0、但 JSON 状态为 error”的业务失败响应。
- 不再把美团地址接口失败误报为“地址簿为空”。
- 授权失效或返回 401 时，明确引导当前用户重新授权自己的美团账号。
- 地址接口暂时异常时，页面提供“重新读取地址”和“重新授权美团”入口。
- 只有美团明确返回空地址列表时，才提示用户在美团 App 中补充收货地址。
- 美团原始错误文本不会直接显示到网页，避免地址、手机号或内部信息泄露。

## 用户可见变化

“帮我买”页面会区分两种状态：

1. **美团已明确返回空地址簿**：提示在美团 App 中添加或完善地址，然后重新读取。
2. **美团地址接口暂时不可用**：提示稍后刷新，并提供重新授权入口，不再声称用户没有地址。

## 部署说明

本版本使用镜像标签 `tropos-candidate:3.2.6-20261101`，生产更新叠加文件为：

`deploy/docker-compose.update-3.2.6.yml`

更新时保留服务器现有 `.env.production`、`deploy/data` 以及 `deploy/meituan/runtime/state`，不要用部署包内的示例配置覆盖这些运行数据。
