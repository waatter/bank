# TROPOS 测试说明

## 运行方式

在仓库根目录，使用 Python 3.10+ 与 Node.js 18+：

```bash
python3 -m unittest discover -s tests -p 'test_*.py' -v
node --test tests/*.cjs
```

默认自动化使用合成数据及本地替身，不需要模型密钥，不创建真实美团订单。外部模型真实检查须另行明确配置。

## 用例覆盖

| 方向 | 主要观察 |
| --- | --- |
| 身份与会话 | 注册登录、用户隔离、会话失效、密码重置与 MFA |
| 账本和交易 | 确认凭证、版本与有效期、余额和现金约束、事务及幂等 |
| 状态变化 | 工资延期、到账、账单与订阅变化后的重算 |
| 模型边界 | 非法动作、金额及字段校验、超时与格式降级 |
| 客户端 | 会话恢复、请求超时、交互状态与账户切换 |
| 外部连接器 | 参数、授权目录、订单状态与模拟账本隔离 |

具体断言保存在 `tests/`。客户端部分测试使用替代 DOM，不等于真实浏览器验收。
