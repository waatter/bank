# TROPOS 3.2.2 热修复说明

## 修复内容

认证界面的异步提交处理器原先在 `await` 之后继续读取
`event.currentTarget`。浏览器在异步边界后会把该属性清空为 `null`，
因此即使服务端已经完成登录、发信或重置密码，页面仍会显示：

```text
Cannot read properties of null (reading 'reset')
```

3.2.2 在提交处理器进入异步流程前保存稳定的表单引用，并使用该引用读取和
清空字段。修复覆盖登录、MFA 登录、注册、找回密码、重置密码、绑定邮箱、
开启 MFA 和关闭 MFA 八个表单。

## 升级影响

本次只修改浏览器端认证交互和版本号，不修改数据库结构、认证令牌格式、SMTP、
模型配置、连接器配置或账本数据。已经在 3.2.1 中成功执行但随后显示前端错误的
登录或密码重置操作不需要回滚；刷新页面后应以服务端实际状态为准。
