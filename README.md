# TROPOS：知己·善谋·择时·守诺

基于动态金融画像与四引擎协同的自适应银行智能体。参赛项目策划书和概念说明见 [TROPOS 完整项目策划书](./TROPOS_完整项目策划书_v1.0.md)。

## 当前内容

- [概念展示页](./index.html)：项目定位、四引擎、产品模式与演示主线。
- [银行智能体工作台](./demo.html)：可交互原型（样式与逻辑在 `assets/`），包含：
  - **Agent 工作台**：用自然语言下达指令，按 ETHOS → METIS → KAIROS → ARGOS 逐步展示执行轨迹；三位合成用户面对同一句话得到不同策略（千人千策）；未来 30 天现金路径图标出预留线、缺口和双 11；"工资晚 15 天"会冻结依赖收入的任务，并对比"旧计划照常执行"与"TROPOS 重规划"。
  - **先别买 · 双 11 冷静期**：提交购物申请（为什么买、替代品、付款方式、使用频率），依次经过冲动消费风险画像、现金流与分期成本测算、匿名陪审团（模拟投票）、冷静期和付款守护，得出"先别买 / 再等 24 小时 / 可以买"。风险高的用户可以自行开启「冷静期守护」，开启后高风险的分期或信用付款要等冷静期结束再确认。
  - **账单与订阅**：分类可追溯到交易；交易备注里的注入指令会被隔离；只有收到服务商回执后才显示"已取消"。
  - **智能转账**：校验同名收款人消歧、限额、现金预留、收入依赖和指令来源，最后逐笔确认；可演示接口超时后按幂等键查询、拦截重复提交。
  - **执行记录**：按引擎筛选的审计时间线。

## 查看原型

直接在浏览器打开 `demo.html`，不需要安装依赖、联网或配置密钥，适合离线路演。

建议演示顺序（约 3 分钟）：

1. 在工作台点"帮我打理这 2 万元…"，再点"换成「陈工」再问一次"，展示同一句话得到不同策略。
2. 切回阿林，点"工资晚 15 天"，看曲线跌破预留线，再看"原计划 vs 新计划"并采纳。
3. 点"注入测试"，展示 ARGOS 拦截。
4. 切到小周，打开「先别买」，选"护肤套装"或"新款手机"，看审批流和结论；开启冷静期守护后再点"我还是要买"。

## 设计与边界

- 风险识别只看现金流与消费行为信号（深夜消费占比、在还分期、信用卡还款状态、可灵活资金），不使用年龄、职业、性别、地域等身份标签。
- 冷静期守护由用户授权开启、随时可关；TROPOS 不替用户下单，也不会永久禁止消费。
- 意图识别与四引擎决策目前是 `assets/demo.js` 里的规则实现，用来说明交互和约束逻辑，不代表已接入大模型或真实银行接口。接入真实 Agent 时，替换 `route()` 和各 `*Reply()` 函数即可。
- 账户、交易、账单、订阅、投票和回执都是合成示例数据。原型不连接银行账户、不执行真实交易，也不构成金融建议；界面上的"成功"只表示浏览器内的演示状态已变更。分期手续费率 0.6%/期 为示例值。
