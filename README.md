# TROPOS：知己·善谋·择时·守诺

基于动态金融画像与四引擎协同的自适应银行智能体。参赛项目策划书和概念说明见 [TROPOS 完整项目策划书](./TROPOS_完整项目策划书_v1.0.md)。

## 当前内容

- [概念展示页](./index.html)：「同一家银行，三扇不同的窗」。首屏并排展示三位用户各自的窗，接着是窗的读法、四位伙伴、管理模式、收入冲击演示、「先别买」和业务覆盖。
- [银行智能体工作台](./demo.html)：可交互原型，样式与逻辑在 `assets/`。

### 设计思路：三扇窗

界面随知己（ETHOS）的画像而变，不只是策略随人变：

| 用户 | 处境与心理偏好 | 窗外 | 字体与口吻 |
|---|---|---|---|
| 阿林 | 自由设计师，收入不定，最想知道"稳不稳" | 清晨，雾蓝与晨光 | 宋体；一次只给一个结论 |
| 小周 | 分期叠加、常在深夜下单，怕被评判 | 深夜，城市灯火与月亮 | 楷体；温和，不催促，用柔和的珊瑚色代替警告红 |
| 陈工 | 工程师，收入稳定，要精确和掌控 | 正午，天空里的制图网格 | 黑体；数字先行，直接给结论 |

窗外的风景就是接下来 30 天的现金：山的高低是每天的余额，水面是安全线，山脚被水没过的日子就是钱会紧的日子。工资延期时窗外下雨，采纳新安排后雨停。

### 页面

- **窗**：首屏是窗景，天空里直接写当前结论；下方是关键数字、对话（四位伙伴按顺序签名留痕）、接下来 30 天的日程和「此刻的你」。下雨后会出现"照旧执行 vs 重新安排"对比。
- **先别买 · 双十一冷静期**：一张购物申请单，知己、善谋、陌生人、择时、守诺依次盖章，最后落一枚结论印章。高风险状态的用户可以自行开启冷静期守护；判断只看行为与现金流信号，不使用身份标签。
- **账本**：分类追溯到交易；交易备注里的注入指令被隔离为只读文字；订阅取消以商家回执为准。
- **转账**：像寄信一样逐项盖邮戳（收款人消歧、限额、安全线、收入依赖、指令来源），演示接口超时后按凭证号查询、拦截重复提交。
- **日记**：按伙伴筛选的审计记录。

## 查看原型

直接在浏览器打开 `index.html` 或 `demo.html`，不需要安装依赖或配置密钥。字体（霞鹜文楷、思源宋体，均为开源字体）通过 jsdelivr 加载；断网时会回落到系统自带的楷体和宋体，功能不受影响。

建议演示顺序（约 3 分钟）：

1. 在右上角依次点三扇窗（阿林、小周、陈工），展示界面、语气和结论如何随人而变。
2. 在阿林的窗前说"帮我打理这 2 万元…"，再点"换成「陈工」再问一次"：同一句话，不同策略。
3. 点"如果工资晚 15 天"：窗外下雨，山脚被水没过；看"同一场雨，两种过法"并采纳，雨停。
4. 点"试一句越权的话"，展示守诺拦截。
5. 切到小周，打开「先别买」，选"护肤套装"：五枚章依次盖下，落下"先别买"；开启冷静期守护后再点"我还是想买"。

## 设计与边界

- 设计取舍参考了 Anthropic 公开的 frontend-design skill：避开奶油底色加赤陶点缀、千篇一律的圆角卡片、每个标题上都压一行英文小标签等常见的生成式套路，把大胆只用在"窗"这一处。
- 风险识别只看现金流与消费行为信号（深夜消费占比、在还分期、信用卡还款状态、可灵活资金），不使用年龄、职业、性别、地域等身份标签。
- 冷静期守护由用户授权开启、随时可关；TROPOS 不替用户下单，也不会永久禁止消费。
- 意图识别与四引擎决策目前是 `assets/demo.js` 里的规则实现，用来说明交互和约束逻辑，不代表已接入大模型或真实银行接口。接入真实 Agent 时，替换 `route()` 和各 `*Reply()` 函数即可。
- 账户、交易、账单、订阅、投票和回执都是合成示例数据。原型不连接银行账户、不执行真实交易，也不构成金融建议；界面上的"成功"只表示浏览器内的演示状态已变更。分期手续费率 0.6%/期 为示例值。
