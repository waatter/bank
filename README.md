# TROPOS：知己·善谋·择时·守诺

基于动态金融画像与四引擎协同的自适应银行智能体。参赛项目策划书和概念说明见 [TROPOS 完整项目策划书](./TROPOS_完整项目策划书_v1.0.md)。

## 当前内容

- [概念展示页](./index.html)：项目定位、四引擎、产品模式与演示主线。
- [模拟银行工作台](./demo.html)：可交互的初步原型，覆盖画像切换、账单与订阅、转账约束检查、用户确认、收入延期重规划和执行记录。

## 查看原型

直接在浏览器打开 `demo.html`。当前版本是单文件静态原型，不需要安装依赖或配置密钥。

原型中的账户、交易、账单、订阅和回执都是合成示例数据；它不连接银行账户、不执行真实交易，也不构成金融建议。界面显示的“模拟成功”只表示浏览器内的演示状态已变更。

## 协作

- 在 GitHub 上通过分支和 Pull Request 共享、审阅并合并改动。
- 每位合作者可在自己的 Codex 会话中打开同一仓库；仓库权限共享不等于聊天上下文或本地文件权限共享。
- 真实账户数据、受许可限制的数据和密钥不要提交到仓库。研究复现材料应使用合成数据或获准的安全存储，并保留必要的数据说明。
