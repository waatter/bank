# TROPOS · 千人千策，随境而变

**读懂人的处境，善作每一份安排。**

2026 FinTechathon 深圳国际金融科技大赛 · 微众银行金融科技大学生挑战赛 · 国内人工智能赛道

**咪咪大王队**：刘水、余冠辰 · 复旦大学经济学院
当前版本：**3.2.9**

“帮我打理这两万元。”同一句话，现金紧张的人需要先留住房租和还款，有充足缓冲的人可以为未来多作安排。即使是同一个人，工资晚到、账单增加，昨天合理的计划也需要重新检查。

TROPOS 将自然语言办理、动态金融画像与现金规划连接起来：先理解用户的目标和处境，再形成有依据的方案；用户确认后，由服务端核验、记账并提供回执。我们希望每一笔银行操作，都能服务于一个人更完整的生活。

## 四位协作者，各有所守

| 职责 | 如何帮助用户 |
| --- | --- |
| **知己 ETHOS** | 确认目标、资金期限与现金底线，结合当前账本理解处境 |
| **善谋 METIS** | 计算未来 30 天现金路径、必要支出与可安排空间，解释方案依据 |
| **择时 KAIROS** | 收入或账单变化后重新检查计划，让行动跟随最新状态 |
| **守诺 ARGOS** | 核对授权与业务规则，保留确认、交易记录和回执 |

四个名字代表贯穿产品的协作职责。模型辅助理解和生成候选方案，服务端规则负责金融计算与执行校验，用户掌握最终决定权。

## 可体验的项目亮点

**让画像真正影响安排。** 目标、收入稳定性、必要账单和现金底线共同影响建议。长期偏好由用户更正，短期事件触发重新计算，让画像持续服务于具体行动。

**让变化进入判断。** 系统分开呈现今日余额、预计收入和未来现金压力。工资延期或新增支出后，旧方案接受重新检查；条件恢复后仍由用户重新确认。

**让自然语言抵达银行事务。** 支持转账、账单分析、订阅办理、多步骤任务，以及卡片和理财的沙箱子流程。同名收款人先澄清，关键变更先展示影响，再确认。

**让结果经得起核对。** 常规转账具备方案确认、版本与有效期校验、事务记账和幂等回执。遇到结果未知时，按原事项查询，减少重复执行风险。

**让金融解释更亲近。** 财务体检同时展示数据、规则、未知项和下一步；金融白话解释与长辈友好显示帮助用户理解关键信息。

## 五分钟启动

需要 **Python 3.10+**。银行后端及 Python 测试使用标准库；首次体验不需要模型密钥。

```bash
git clone https://github.com/waatter/bank.git
cd bank
python3 -m backend.server --host 127.0.0.1 --port 8765 --db .local/tropos.sqlite3
```

Windows 可使用 `python` 替代 `python3`，或双击根目录的 `一键启动-TROPOS.cmd`。

打开 **http://127.0.0.1:8765/index.html** 了解项目，进入 **http://127.0.0.1:8765/demo.html** 体验工作台。可选择共享 A/B/C 演示身份，或注册独立合成账户。

本地规则模式可体验主要银行沙箱流程。外部模型可在模型中心按说明接入；自带密钥调用可能产生服务商费用。更多配置见[部署指南](docs/部署指南.md)。

## 运行与数据边界

银行账户、余额、交易和银行回执均为合成数据，适用于比赛演示和技术研究。注册账户独立，共享 A/B/C 身份供演示使用。当前没有后台自动付款执行器。

外部模型、SMTP 和美团连接器可能产生真实请求。真实跑腿功能依赖单独部署的官方组件和用户授权，支付由用户在美团完成，不扣合成银行余额；因上游许可边界，官方组件不随本仓库分发。详见[美团部署说明](docs/TROPOS_3.2.3_美团连接器部署说明.md)。

评委本机体验使用默认回环地址。公开网络部署的配置要求与已知事项见[部署指南](docs/部署指南.md)及安全自评报告。模型请求可能发送当前消息、有限历史和经授权的必要汇总，请勿输入真实金融凭证或秘密。
