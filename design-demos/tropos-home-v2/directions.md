# 首页方向卡（第二轮）

背景：第一轮（tropos-home，Codex 执行）用户反馈「太奇怪」——「从最初的想法开始」文案别扭、
缺中文字体与 UI 之美、四角色立意没立起来。本轮的三个完整方向针对这三点重做：
中文排版用宋体/黑体分层、四引擎（知己 ETHOS / 善谋 METIS / 择时 KAIROS / 守诺 ARGOS）为叙事主轴、
slogan「千人千策，随境而变」取代「知你所想，善作安排」成为首页第一主张。
素材为项目自有：tropos-mark.svg、本地 Noto Sans SC + Manrope、策划书中的希腊词源与约束公式。

## 完整三方向

**A · 纸面宣言**（编辑排版，宋体大标题）
主张：千人千策，随境而变。首屏是一句话的宣言，四引擎是四个章节：知 / 谋 / 时 / 守，
各配希腊词源批注（ethos 品格与习惯、mētis 谋略的智慧、kairos 恰好的时机、Argos 奥德修斯的忠犬）。
形式来自题材本身：银行是契约与碑刻的行业，宋体大字 + 细线 + 大量留白 = 庄重与可信。
避开暖奶油 AI 默认：冷纸白 #FAFAF7、墨黑、守诺金 #B27D45、深绿 #315F5A。
最大胆处：把四引擎写成四个汉字章节，竖排对联收束全页。

**B · 星图**（深海军蓝，工程叙事）
主张：One Banking Agent, Adaptive to Every Financial Life. 策划书自己指定的视觉：
深海军蓝底 + 知己蓝 #5B8DEF / 善谋紫 #9B7EDE / 择时绿 #4EC98A / 守诺金 #D9A45B。
首屏是四道气流汇入金色中心点（= 用户的选择，呼应 tropos-mark）的动态星图；
中段是 Profile→Policy→Plan→Execution→Feedback 闭环管线图和现金约束公式（等宽字体代码卡），
证明「有顶级工程师」；ARGOS 以跨层网关出现，写明「对不安全的行为拥有否决权」。
最大胆处：把系统架构做成首页主角，而不是把架构藏进文档。

**C · 同言**（产品即首页，分屏对照）
主张：同一句话，不同的安排。首屏中央只有一张输入卡：「帮我打理这两万元」；
下方整屏一分为二——左边现金流紧张者、右边储备充足者，同一指令产出两份不同的安排清单。
切换「工资延迟 15 天」，两侧计划当场重排，变更行高亮。底部深色横带：每一次执行，先过守诺这一关。
形式直接来自决赛记忆点「同一句话 + 相同金额，不同的行动与解释」。
最大胆处：首页不讲理念，首页就是演示。

## 备选（缩略）

**D · 活字钤印**：宋体活字网格 + 「守」字朱文印，银行契约感的极致中式方向；偏静态，互动弱。
**E · 资金天气**：30 天余额曲线作全页主角的报纸图表风；与现有首页的试算卡重叠，新意不足。
**F · 蓝图**：淡蓝图纸网格上的四引擎工程图；与 B 同属工程叙事但少了色彩体系，并入 B。

完整流程说明：三方向各自独立构图，未参照外部作品截图；所有文案与数据均出自项目策划书、
README 与现有首页，未编造评价、数据或 logo。等用户选定方向后再实现正式 index.html。
